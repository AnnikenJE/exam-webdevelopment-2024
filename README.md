## 🗽Case: TrumpVerse

**Disclaimer:** Case was provided by school. The project focuses solely on fullstack web development and does not express political opinions or support.

TrumpVerse is a fullstack web application developed as an exam project in Web Development. The solution consists of a React-based frontend and a .NET Web API backend with a database for managing TrumpMerch.
The application supports full CRUD functionality, image uploads, and API documentation in wwwroot, ensuring seamless interaction between frontend and backend.
